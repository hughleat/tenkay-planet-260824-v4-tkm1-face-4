# Tenkay planet graph — S2 face 4

Immutable graph data for `planet-260824-v4`, distributed as gzip-compressed
TKM1 layout-1 blocks. Decompress a `.tkm.gz` file to obtain a memory-mappable
little-endian TKM1 file. Graph IDs use `s2-midpoint-v2`.
